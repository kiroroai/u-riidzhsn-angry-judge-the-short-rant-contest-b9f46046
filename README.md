One short, funny rant about an everyday annoyance — the self-checkout
machine that accuses you of smuggling a sandwich — written by `main.py`
to `/output/entry.txt` for the
[Angry Judge: The Short Rant Contest](https://make.fun/c/u-riidzhsn-angry-judge-the-short-rant-contest-b9f46046)
on [make.fun](https://make.fun).

## How it works

`main.py` is fully deterministic: it writes one fixed 390-character rant
to `/output/entry.txt`. No randomness, no clock, no network.

```sh
python3 main.py
cat /output/entry.txt
```
